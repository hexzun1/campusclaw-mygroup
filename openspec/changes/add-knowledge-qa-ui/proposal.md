## Why

迭代 2（`add-traceable-vector-retrieval`）已经提供了班级范围内、结果可溯源的 `POST /api/search` 与带引用的问答 `POST /api/ask`，但它们只能用 curl 调用，教师和学生在页面上用不到。本变更只补前端：让本班成员在登录后直接检索材料、提问，并在页面上核对每条结果、每个 `[n]` 引用来自哪份材料的哪一段。

## What Changes

- **导航**：登录后的页面顶部增加导航，「材料」「知识检索」「知识问答」三个标签并列；学生与教师都能访问三个页面，未登录访问任何一个都回到登录页。
- **知识检索页**：输入问句，可选检索模式 `keyword` / `vector` / `hybrid`（默认 `hybrid`）；逐条展示材料标题、切片序号、字符偏移区间与摘录；无命中时显示「资料中未找到相关内容」。
- **知识问答页**：对话式界面。页面顶部说明："每个问题先在本班做混合检索，取前 4 条切片再生成简短回答，并标出 [1]、[2]；没有命中时不调用模型"。用户的问题靠右显示；回答放在标题为「依据回答」的卡片里，卡片下方按 `[1]`、`[2]` 的顺序列出出处（材料标题、切片序号、偏移区间、摘录），编号与回答中的标注一致；无命中时只显示固定文案「资料中未找到相关内容」，不显示出处。
- **错误与登录态**：接口返回 503 时提示「检索服务暂不可用」；返回 401 时清除 token 并回到登录页；所有请求带 `Authorization: Bearer <token>`，不依赖 Cookie。
- **不做**：流式输出、保存历史会话、修改任何后端接口（详见 Non-goals）。
- **取代迭代 2 的一条非目标**：`add-traceable-vector-retrieval` 的 proposal 在 Non-goals 中写了"前端检索页面：不做检索与问答的前端界面"。本变更**有意取代**这一条——检索与问答的页面自此纳入范围；该 proposal 里的其余非目标（重排序、框架、流式对话、跨班检索等）不变。

## Capabilities

### New Capabilities

- `knowledge-qa-ui`：检索页与问答页的页面行为——导航与访问控制、检索模式与结果展示、问答的对话展示与出处列表、错误提示、渲染安全与不落地。

### Modified Capabilities

（无——不修改任何已有 Requirement。后端行为仍由 `knowledge-retrieval` 定义；登录态与 Bearer 头的约束仍由 `auth-upload` 的「前端页面行为」定义，新页面按其执行。）

## Impact

- **前端**（`frontend/`）：新增 `pages/SearchPage.tsx`、`pages/AskPage.tsx`；新增共享的页面布局（顶部导航 + 现有的用户信息、主题切换、登出）；`App.tsx` 增加 `/search`、`/ask` 两条受保护路由；`pages/MaterialsPage.tsx` 的页头改用共享布局；`api/client.ts` 增加 `searchKnowledge`、`askKnowledge` 及其类型；`index.css` 增加导航、检索结果、对话与出处的样式（沿用现有主题变量，深浅色均可用）。
- **后端、接口、数据库、Docker 编排**：不变。
- **依赖**：不新增 npm 依赖。
- **文档**：README 增加两个页面入口的说明；`docs/iteration-2.md` 注明"不做前端检索页"已被本变更取代（仅加一句说明）。
- **前置状态**：这些页面调用的接口由 `add-traceable-vector-retrieval` 提供；验收依赖它已部署（含网关桩或真实网关）。本变更新增的是全新能力，归档不依赖其它 change 的归档顺序。

## Non-goals（非目标）

- **流式输出**：回答等接口一次返回完整 JSON 后一次性显示，不做 SSE / 逐字输出。
- **保存历史会话**：问答页的对话只存在于页面内存中，刷新、离开页面或登出即消失；不写入 `localStorage` / `sessionStorage`，也不新增后端存储。
- **多轮上下文**：每个问题独立提问，页面**不**把此前的对话作为 `messages` 发给后端；追问时需要把指代补全成完整的问题。
- **修改后端**：不新增、不改动任何接口、错误码或响应字段；`top_k`、检索阈值、前 4 条等取值沿用后端。
- **检索参数面板**：不提供返回条数、阈值、切分策略等高级选项；只有检索模式一项可选。
- **材料页联动**：不做"从出处跳转到材料详情 / 高亮原文"，出处只展示文字信息。
- **富文本渲染**：检索摘录与模型回答都按纯文本显示，不做 Markdown / HTML 渲染。
- **新的角色规则**：不区分教师与学生的可见内容，两者看到的页面与功能相同（上传与重建入口仍只在材料页且仅教师可见，本变更不动）。
