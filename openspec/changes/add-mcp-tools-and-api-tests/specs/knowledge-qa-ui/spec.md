## MODIFIED Requirements

### Requirement: 页面导航与访问控制

已登录页面的顶部 MUST 提供导航：「材料」「知识检索」「知识问答」「助手」四个标签对所有登录用户并列显示；教师 MUST 另外看到「智能体管理」「技能管理」「工具服务器」三个标签，学生 MUST 看不到这三个标签。当前页面对应的标签 MUST 有明确的选中标识。学生与教师 MUST 都能访问材料、知识检索、知识问答与助手四个页面，且在知识检索、知识问答两页看到相同的功能。未登录时访问知识检索页、知识问答页、助手页或三个管理页 MUST 回到登录页；学生访问三个管理页的地址 MUST 回到材料页。页面上的访问限制只是显示层面的处理，真正的鉴权由服务端接口完成。

#### Scenario: 三个标签并列且标出当前页

- **WHEN** 任意角色登录后打开材料页
- **THEN** 页面顶部 MUST 仍同时显示「材料」「知识检索」「知识问答」三个标签，并在其后显示「助手」标签
- **AND** 「材料」标签 MUST 处于选中状态
- **AND** 点击其它标签后 MUST 进入对应页面，且该标签变为选中状态

#### Scenario: 管理标签只对教师显示

- **WHEN** teacher_a 与 student_a1 分别登录并查看导航
- **THEN** teacher_a MUST 看到「智能体管理」「技能管理」「工具服务器」三个额外标签
- **AND** student_a1 MUST 看不到这三个标签；直接访问它们的地址时 MUST 回到材料页

#### Scenario: 学生与教师都能使用检索和问答

- **WHEN** student_a1 与 teacher_a 分别登录并打开知识检索页与知识问答页
- **THEN** 两个角色 MUST 都能看到并使用输入框、提交按钮，功能与展示一致
- **AND** 不因角色不同而隐藏这两个页面

#### Scenario: 未登录不能进入新页面

- **WHEN** 未登录用户直接访问知识检索页、知识问答页、助手页或三个管理页的地址
- **THEN** 页面 MUST 回到登录页，且 MUST NOT 发出检索、问答、会话或管理请求

#### Scenario: 刷新后停留在当前页

- **WHEN** 已登录用户在知识检索页、知识问答页或助手页刷新浏览器
- **THEN** 页面 MUST 仍停留在该页面
- **AND** 输入框中的内容与页面上已显示的结果 MAY 被清空
