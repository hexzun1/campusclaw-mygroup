# 迭代 3 说明（v0.3.0-knowledge-qa-ui）

规约：`openspec/changes/add-knowledge-qa-ui/`（纯前端变更：顶部导航 + `/search` 检索页 + `/ask` 问答页；不改 `backend/` 与任何接口）

## 验收环境与方式

- 开发环境：`docker compose -f docker-compose.dev.yml up -d`（api 在 `127.0.0.1:8081`，db、qdrant、网关桩 8090）+ Vite 前端 `127.0.0.1:5174`（`/api` 代理到 8081）。
- 自动验收接确定性网关桩：用一份仓库外的本地 compose override 把 api 的 `EMBEDDING_BASE_URL` / `CHAT_BASE_URL` 指向 `http://stubgateway:8090`（不改仓库文件、不动 `.env`）；桩可断言"模型被调用了几次"。
- 账号：student_a1、teacher_a（A 班）、student_b1（B 班），口令取自本机 `.env`。
- 浏览器实测为主：请求体与请求头用控制台 `window.fetch` 记录片段核对；依赖故障用 `docker compose -f docker-compose.dev.yml stop qdrant`；登录失效用向 `revoked_tokens` 插入当前 token 的 `jti`；400 与断网用一次性 `fetch` 包装伪造。
- 生产验证：`docker compose -f docker-compose.yml up --build -d --no-deps web` 重建 web 后，在 `http://localhost:8080`（Nginx + 严格 CSP）走查。

## 按 Requirement 的验收结果

### 1. 页面导航与访问控制

- **三个标签并列且标出当前页：通过**。student_a1 与 teacher_a 登录后顶部并列显示「材料」「知识检索」「知识问答」；依次点击后地址变为 `/materials`、`/search`、`/ask`，`aria-current="page"` 落在当前标签上（读取 `a[aria-current="page"]` 与地址一致）。
- **学生与教师都能使用检索和问答：通过**。两个角色都看到并使用了检索输入框与提问框（student_a1 完成三种模式检索与多轮问答；teacher_a 在检索、问答与上传页均正常），无按角色隐藏。
- **未登录不能进入新页面：通过**。登出状态下直接打开 `/search`、`/ask` 都回到登录页，且 `fetch` 记录中没有任何 `/api/search`、`/api/ask` 请求。
- **刷新后停留在当前页：通过**。登录后在 `/search`、`/ask` 各刷新一次，仍停留在原页面并保持登录态。

### 2. 知识检索的输入与模式

- **默认使用混合模式：通过**。打开页面直接提交「教学材料」，请求体恰为 `{"query":"教学材料","mode":"hybrid"}`。
- **按所选模式检索：通过**。把模式切到「关键词」「向量」后，请求体分别为 `{...,"mode":"keyword"}`、`{...,"mode":"vector"}`。
- **空问句不发请求：通过**。输入为空或只有空格时提交按钮禁用，强制点击也没有请求（记录 0 条）。
- **请求不携带班级信息：通过**。请求 URL 为 `/api/search`，请求体只有 `query` 与 `mode`；请求体、query 与自定义 Header 中都没有 `class_id`、`role`、`top_k`；请求头含 `Authorization: Bearer <token>`。
- **超长问句无法提交：通过**。向输入框粘贴 600 个字符，实际进入 500 个（`maxLength=500`），提交的 `query` 为 500 字。
- **请求进行中不能重复提交：通过**。包装 `fetch` 让响应延迟 2 秒：期间按钮变为「正在检索…」且禁用，连续补点两次没有产生新请求，最终记录恰 1 条。

### 3. 检索结果展示

- **命中结果逐条展示：通过**。student_a1 以 `hybrid` 检索「教学材料」得 2 条命中，页面逐条展示并与其后同一问题 `curl` 的 `hits` 逐字段一致（含顺序）：`[1]`《A 班教学材料示例》切片序号 0、字符 0–32；`[2]`《持久化验证材料》切片序号 0、字符 0–39。摘录以 `white-space: pre-wrap` 保留换行。
- **无命中的统一提示：通过**。检索乱码串「zzzzqqq毛毛虫」只显示「资料中未找到相关内容」，无任何条目。
- **新结果替换旧结果：通过**。第二次检索（关键词「校史馆」，1 条）返回后第一次的条目全部消失；故障场景中，一次成功检索后再提交 `hybrid` 得到 503，页面不再保留上一次的条目，只显示失败提示。

### 4. 知识问答的对话展示

- **顶部说明文字：通过**。页面顶部逐字显示「每个问题先在本班做混合检索，取前 4 条切片再生成简短回答，并标出 [1]、[2]；没有命中时不调用模型」，含要求的三个关键短语。
- **用户问题靠右显示：通过**。问题气泡右边缘与对话容器右边缘重合（间距 0px），气泡中心位于容器右半侧；回答卡片渲染在该问题之后（下方）。
- **每个问题独立提问：通过**。先后提问两个问题，请求体分别恰为 `{"question":"教学材料是做什么用的"}` 与 `{"question":"校史馆的参观时间是什么时候"}`；第二条不含第一个问题及其回答，无 `messages` 字段，无 `system` 内容。
- **空问题与超长问题：通过**。空白问题按钮禁用、无请求；粘贴 1100 个字符只进入 1000 个（`maxLength=1000`）。
- **回答返回前不能连续提问：通过**。延迟 3 秒响应期间，问题旁显示「正在生成回答…」、输入与按钮禁用；期间补点提交没有第二个请求（最终记录恰 1 条）。

### 5. 依据回答与出处列表

- **回答与出处编号一致：通过**。student_a1 提问「教学材料是做什么用的」：页面显示标题为「依据回答」的卡片，回答文字与同一问题 `curl` 的 `answer` 逐字一致（`stubgateway 依据收到的资料作答： [1] [2] [3]`）；卡片下方 3 条出处依次标注 `[1]`、`[2]`、`[3]`，其标题、切片序号、字符区间与摘录与 `citations` 完全一致；回答中的 `[n]` 均落在 1–3。
- **不补造出处：通过**。只在 1 条 `citations` 的回合（「校史馆的参观时间」），页面恰好列出 1 条，未按回答文字中出现的其它编号增删。
- **无命中只显示固定文案：通过**。乱码提问的回合只有「资料中未找到相关内容」；整页无「依据回答」卡片、无出处列表元素。
- **出处不越过班级：通过**。就只存在于 B 班材料的内容提问（「天文观测在哪里集合」），页面只显示「资料中未找到相关内容」；整页文本不含「B 班天文观测安排」「红色头灯」「山顶观测站」等 B 班标题或摘录。

### 6. 检索与问答的错误处理

- **服务不可用时的提示：通过**。停 qdrant 后以 `hybrid`、`vector` 检索，页面显示「检索服务暂不可用」，页面文本不含 `qdrant`、`6333`、`api-key`。
- **关键词模式在依赖不可用时仍可用：通过**。同一故障窗口内以 `keyword` 检索 A 班存在的词（「校史馆」）正常返回 1 条命中、无 503 提示；重启 qdrant 后 `hybrid` 恢复 2 条命中。
- **登录失效回到登录页：通过**。向 `revoked_tokens` 插入当前 token 的 `jti` 后提交：检索页与问答页均回到登录页，`sessionStorage` 中 token 已清除，页面上不显示错误文案。
- **请求被拒绝时显示原因：通过**。一次性 `fetch` 包装返回 400 `{"error":"检索词不能超过 500 个字符"}`，页面显示该原因且按钮恢复；改词后重新提交成功。
- **失败后对话仍在：通过**。先完成一轮成功问答，停 qdrant 后提第二个问题：第二轮旁显示「检索服务暂不可用」，第一轮的「依据回答」卡片仍在，输入框恢复可用；重启 qdrant 后重新提问成功。

### 7. 渲染安全与内容不落地

- **HTML 与脚本按文字显示：通过**。teacher_a 上传《渲染安全测试材料》（`render-safety.md`，含 `<script>alert(1)</script>`、`<b>加粗</b>`）；先把 `window.alert` 替换为记录函数，再在检索页与问答页命中它：这些字符原样显示为文字，0 次 alert，结果区内（`.hits-list` / `.ask-turns`）0 个 `script/b/h1/strong/ul` 元素。
- **Markdown 标记不被渲染：通过**。同一材料中的 `# 标题渲染测试`、`**粗体**`、`- 列表` 在检索摘录与问答出处中均按原文显示。
- **对话不落地：通过**。完成检索与问答后，`sessionStorage` 只有 `campusclaw_token`、`localStorage` 0 项、`document.cookie` 为空；问答页刷新后对话消失；切到「材料」再切回，此前的对话消失。
- **内容安全策略下无违规：通过**。重建生产 web 后在 `http://localhost:8080` 完成登录、三个标签切换、keyword 检索命中、提问出卡、主题切换（light→dark）、登出；在 `/search`、`/ask` 直接刷新仍返回应用（Nginx 回退生效）；`securitypolicyviolation` 监听贯穿整个流程记录 0 条，控制台无策略违规。
